Пример промта для генерации A2V10 XAML через MCP:

Сгенерируй XAML для экрана: [краткое описание экрана].

Требования:
1) Перед генерацией получи допустимые теги и атрибуты через MCP tools:
   - GetAllTags
   - GetAttributesForTag (для каждого используемого тега)
2) Используй только существующие теги и атрибуты A2V10.
3) После генерации обязательно вызови ValidateXamlDocument.
4) Если IsValid = false:
   - исправь ошибки,
   - повтори ValidateXamlDocument,
   - верни только финальную валидную версию.
5) Не используй несуществующие теги/атрибуты даже если они “похожи” на стандартный XAML.

Формат ответа:
- Сначала кратко: какие проверки выполнены.
- Затем финальный XAML без пояснений внутри кода.

Короткий пример запроса:

Сгенерируй форму редактирования клиента:
- Поля: Name, Email, Phone
- Кнопки: Save, Cancel
- Валидация обязательности Name и Email
Сделай по правилам выше с обязательной проверкой через ValidateXamlDocument.
